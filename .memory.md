# Persistent Assistant Memory

## Operating Constraints & Style
- Line length strictly <= 80 characters for all code, markdown files, commit
  messages, and assistant responses.
- Clickable `file://` markdown links required for all files and symbols.
- Never run `git push`; remind Carlos to push.
- Keep changes unstaged until Carlos explicitly instructs to commit.
- Pre-commit hook prompts `Run wile test? [y/N]:`; respond with `"y\n"` via
  `manage_task send_input`.
- **Authorship:** On artifacts where authorship is expected and Antigravity is
  authoring it, state the author as "Antigravity(<model>)" appending
  "on behalf of CarlosJHR64" when appropriate.

## Workflow & Collaboration
- **Carlos:** Pair programming partner and project lead.
- **Fluffy:** Collaborator reviewing pushed commits and writing pull reports.
- **Push Reports:** Prepared for Fluffy upon request from a base commit to
  `tmp/reports/wile-push-<base>..<head>-Report.md`.
- **To-Do List:** Maintain scratch items, carried nits, and postponed tasks in
  `tmp/.todo.md` (gitignored).

## Tooling & Verification Quirks
- **Lexicon:** Reconcile with `bin/wile lexicon --yes` whenever identifiers
  change; verify with `ruby test/tc_lexicon`.
- **Reek:**
  - Multi-line call chains count each line as a statement for
    `TooManyStatements`.
  - `MissingSafeMethod` applies to private `!` methods as well.
  - `InstanceVariableAssumption` warns if ivars are assigned in helpers called
    from `initialize`.
- **RuboCop:** Gate scope is tracked `.rb` files excluding `cache/`.
